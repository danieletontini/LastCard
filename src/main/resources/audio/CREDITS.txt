SUONI E MUSICHE DI ULTIMA CARTA

I file vanno in questa cartella con esattamente questi nomi. Se uno manca, il gioco
resta in silenzio per quel suono, senza errori.

Formato: WAV (PCM 16 bit). Java non riproduce MP3 né OGG: si convertono con Audacity
(File > Esporta > WAV). Per la musica bastano mono e 22050 Hz: il file intero viene
caricato in memoria e finisce nel jar, quindi conviene tenerlo piccolo.

Usare solo file con licenza libera (CC0, CC-BY, licenza Pixabay) e compilare la riga
corrispondente qui sotto. Con CC-BY l'attribuzione all'autore è obbligatoria.
